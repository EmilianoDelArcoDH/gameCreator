# Tutorial

:project Tutorial: Primer proyecto

## Ventana de Proyecto

:position 30,30,40,40

:overlay

### Ventana de Proyecto

La ventana de proyecto se abre cuando creas un nuevo proyecto o abres uno de tus proyectos existentes.
Este es el lugar donde programas, pruebas, creas sprites,
mapas y estableces todos los detalles de tu proyecto.

## Navegacion

### Navegar en el proyecto

Una columna de iconos se encuentra en el lado izquierdo de la pantalla. Te permite
abrir rapidamente el editor de codigo, editor de sprites, mapas, documentacion, configuracion y opciones de publicacion
de tu proyecto.

:highlight #projectview .sidemenu ul


## Seccion Codigo

### Programacion y ejecucion

Haz clic en **Codigo** para abrir la primera seccion.

:highlight #projectview .sidemenu #menuitem-code

:auto


## Seccion Codigo 2

:navigate projects.code

### Programacion y ejecucion

En esta seccion puedes crear tu programa, ejecutar tu aplicacion, probar y depurar.
El lado izquierdo de la pantalla es el editor de codigo, donde escribiras tu programa.
El lado derecho de la pantalla incluye una vista de ejecucion en la parte superior y una consola
en la parte inferior, donde puedes escribir comandos, verificar variables o modificarlas en tiempo real
mientras tu programa se esta ejecutando.

## Seccion Sprites

### Sprites

Haz clic en **Sprites** para abrir el editor de sprites.

:highlight #projectview .sidemenu #menuitem-sprites

:auto

## Seccion Sprites 2

:navigate projects.sprites

### Sprites

Este es el editor de sprites. *Sprites* son imagenes que puedes disenar aqui y luego
referirte desde tu codigo para dibujarlas en pantalla. Haz clic en un sprite en la lista del lado izquierdo
para abrirlo, luego usa las funciones de dibujo en el lado derecho y comienza a dibujar.

## Seccion Mapas

### Mapas

Haz clic en **Mapas** para abrir el editor de mapas.

:highlight #projectview .sidemenu #menuitem-maps

:auto

## Seccion Mapas 2

:navigate projects.maps

### Mapas

Este es el editor de mapas. Los mapas se utilizan frecuentemente para crear niveles para videojuegos, o para
crear entornos que se pueden explorar. Se crean colocando sprites juntos
en una cuadricula. Los sprites se eligen entre los que diseñaste en la seccion de Sprites.

Haz clic en "Agregar Mapa" para crear tu primer mapa y comienza a dibujar en la cuadricula.

## Seccion Doc 2

:navigate projects.doc

### Doc

Aqui esta el editor de documentacion (doc). Cada vez que tu proyecto es un plug-in que
esta destinado a ser utilizado por otros, o una demostracion para la cual deseas agregar explicaciones,
puedes escribir una documentacion aqui usando el lenguaje markdown. Los tutoriales de Digital House Game
se crean con este editor!

## Seccion Configuracion

### Configuracion

Haz clic en **Configuracion** para abrir la configuracion del proyecto.

:highlight #projectview .sidemenu #menuitem-options

:auto

## Seccion Configuracion 2

:navigate projects.options

### Configuracion

En esta seccion puedes editar el titulo y la URL de tu proyecto. Tambien puedes
cambiar la contraseña utilizada para mantener tu proyecto privado mientras te permite probarlo en
diferentes dispositivos. Puedes establecer la orientacion de pantalla adecuada para tu proyecto. Finalmente,
puedes invitar a tus amigos a contribuir a tu proyecto. Todo lo que necesitas para enviar invitaciones es su
apodo de Digital House Game.

## Seccion Publicar

### Publicar

Haz clic en **Publicar** para abrir el panel de opciones de publicacion.

:auto

## Seccion Publicar 2

:navigate projects.publish

### Publicar

Cuando tu proyecto esta completo, puedes hacerlo publicamente disponible para todos los usuarios de Digital House Game.
Tambien puedes mantenerlo privado y exportarlo a HTML5, lo que te permite publicarlo
en tu propio sitio web o en una plataforma de publicacion de juegos.
