## Escribe una palabra

:navigate projects.code.console

### Escribe una palabra

Escribe una palabra con tu teclado, como:

```
hello
```

Luego valida tu entrada presionando la tecla [Return] o [⏎].

:auto #terminal-input

## Respuesta

:navigate projects.code.console

Si escribiste ```hello```, microScript ha respondido con ```0```.

No te enojes, la computadora no quiso ser grosera! Una computadora no es
tan inteligente como piensas. Puede trabajar duro, pero necesita que expreses
exactamente lo que esperas de ella.

Programar significa decirle a la computadora que hacer, usando un lenguaje que pueda
entender.

## Respuesta 2

:navigate projects.code.console

La computadora respondio con ```0``` porque no conoce ```hello```. Busco
en su memoria una *variable* que se llamara así, pero no encontro
nada.

Por lo tanto respondio ```0``` que para ella tambien significa nada, no encontrado, desconocido.
Intentemos enseñarle algo, escribe:

```
hello = 5
```

:auto #terminal-input

## Asignar un valor a una variable

:navigate projects.code.console

Al validar esta linea, acabamos de *asignar* el valor ```5``` a la *variable* ```hello```.
La computadora creo una celda en su memoria, etiquetada "hello" y en la cual almaceno
el valor 5.

Ahora podemos preguntarle de nuevo:

```
hello
```

La consola responde 5! Parece que finalmente aprendio algo.

## Haciendo calculos

:navigate projects.code.console

Pero, puede contar? Intentemos:

```

```

Impresionante verdad? Ahora:

```

```

OK ahora esto es algo, parece que puede usar su memoria y hacer calculos
*simultaneamente*.
Ciertamente podemos sacar algo de esto. Es hora de pasar a la
siguiente tutorial para aprender mas sobre variables.
